### TFEM: a toolkit for the finite element method

TFEM is a toolkit for the finite element method written in modern Fortran. TFEM is intended to be used in education and research.

#### Copyright and use

TFEM is not free software. See file Copyright and file README\_ON\_USE\_OF\_TFEM.


#### Installation of TFEM


(The instruction files are in the folder *install*.)

On macOS: start with file INSTALL.macos and then file INSTALL.linux. 

On Linux systems: see file INSTALL.linux.

On Fedora Linux and similar systems like RedHat and CentOS: see file INSTALL.fedora for some additional hints specific for those systems.

For help on using the nagfor compiler see file README.nagfor


TFEM is not supported natively on MS-Windows. However, by virtualizing
a Linux OS with WSL, Docker or VirtualBox, it is possible to run TFEM on MS-Windows.
